# LiveWall - download

Widget chat per OBS che unisce **Twitch, Kick e YouTube** in un solo overlay, per qualunque streamer.

**Installazione:** scarica **Installa-LiveWall.exe** dalla pagina [Releases](../../releases/latest) e fai doppio clic. Scarica da solo l'ultima versione, crea il collegamento sul desktop e al primo avvio ti guida nella configurazione dei canali.

Requisiti: Windows 10/11 a 64 bit.

In questo repository ci sono solo i file da scaricare; il codice sorgente e la documentazione completa sono nel repository principale.
